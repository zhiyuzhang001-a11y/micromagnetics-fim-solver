# Test scope

Tests are source/developer assets, not default runtime actions. Prepare explicit native resources and install the platform wheel first; use a fresh output directory and account complete-field work for numerical tests. Do not launch historical campaign scripts indiscriminately.

Offline analytic checks: test_skyrmion_postprocess.py, test_postprocess_failures.py, test_postprocess_review.py, test_postprocess_tutorial.py, check_postprocess_rectangular.py. The frozen calibration file is authoritative; recalibration diagnostics must not replace its gates.

Installed contracts: test_installed_package.py. Its preview/state check requires FIMRUN_C4_TEST_STATE pointing to your explicit compatible generated fixture; it is skipped when absent. Private original OVF and workstation-bound stale-kernel fixture scripts are intentionally omitted. Source paths and private data are not test inputs by default.

Optional browser identity/frame/arrow checks require your own Node/Playwright/Chrome and loopback permission. Set FIMRUN_BROWSER_PYTHON to the installed environment's Python and FIMRUN_BROWSER_OUTPUT to a fresh directory; Playwright is a developer dependency, not a runtime requirement. Do not work around execution-permission denials. Full historical native tests carry separate prerequisites and numerical cost. This publication performed static/source/privacy checks only, not another scientific qualification.
