# Offline center-displacement example

The figure plots area-center displacement in nanometres from five synthetic
A/B frame pairs generated by the repository's
[analytic demo](../../fimrun/postprocess/demo.py). The
[postprocessing notebook](../../examples/notebook_skyrmion_postprocess.ipynb)
uses the same public API. Both axes have the same scale, each continuous
segment starts at its first center, and the legend distinguishes the two
sublattices. The deliberately prescribed motion exercises analysis and export.
It provides no physical solver qualification or measured material result.

## Reproduce

Use a disposable clean checkout of source revision `6378ac8`, Python 3.12.14
and NumPy 2.3.5. This uses the repository's
[source-only zero-field test preparation](../../tools/ci/prepare_offline.py).
Run the preparation only in the disposable checkout. Its package identity
is for test use.

```sh
python3 tools/ci/prepare_offline.py
python3 - <<'PY'
import json
import tempfile
from pathlib import Path
from unittest.mock import patch

import fimrun.postprocess as pp
from fimrun.micromagnetics.native import EVALUATIONS, Native

output = Path(tempfile.mkdtemp(prefix="fim-center-")) / "frames"
before = dict(EVALUATIONS)
with patch.object(Native, "__init__", side_effect=AssertionError("Native forbidden")):
    pp.generate_demo(output)
    frames = json.loads((output / "inputs.json").read_text())
    result = pp.analyze(frames, assume_temporal_sampling=True,
                        ab_reference="antiparallel")
    result.plot("center", output=output / "center.svg")
assert before == EVALUATIONS
assert len(result.rows) == 5
print(output / "center.svg")
PY
```

The generated SVG comes from the package's unmodified plot export. The
caption translates the main labels for English readers. The temporal sampling
assertion and antiparallel reference are explicit assumptions for this fixture.
The first and last frames lack a centered velocity estimate.
