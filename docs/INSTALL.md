# Build and install on the qualified platform

Tested platform: macOS 27 arm64, system frameworks, Apple clang/C++17, serial FFTW. The public repository contains source and locks, not the locally accepted wheel or offline installation archives. Do not treat a fresh rebuild as the previously reviewed binary.

With an existing Conda manager, create a fresh environment from the exact same-platform package/build/SHA lock:

```sh
conda create --name micromagnetics --file requirements/conda-osx-arm64-explicit.txt
conda activate micromagnetics
python tools/prepare_package.py --native-prefix "$CONDA_PREFIX"
python -m pip wheel . --no-deps --no-build-isolation --wheel-dir dist
python -m pip install --no-index --no-deps dist/boris_fim_local-0.2.0rc1-py3-none-macosx_27_0_arm64.whl
python -m pip check
python -m ipykernel install --prefix "$CONDA_PREFIX" --name micromagnetics --display-name 'Python (micromagnetics)'
python -m fimrun doctor --native --kernel micromagnetics
```

Choose an unused environment/kernel name if one exists. Prefix-local kernel registration does not replace user kernels; for discovery in an external editor, select the environment interpreter explicitly or register an unused user kernel name. Do not rename a Conda prefix or overwrite an active kernel.

The readable [environment.yml](../requirements/environment.yml) explains dependencies; the exact lock controls package builds. This source build is explicit and may require a compatible Xcode/Command Line Tools compiler. Runtime and offline recovery do not compile code. No fast-math or threaded FFTW is introduced. Build records, actual source/native hashes and platform-tagged wheel metadata are generated by prepare_package.py. See [tests](../tests/README.md) before any numerical qualification.

The standalone recovery installer is not downloaded or executed automatically. Read [RECOVERY](../RECOVERY.md) to assemble and verify your own complete offline archive while the required exact packages are available. A URL or environment YAML alone is not a backup.
